## How we work together

1. **Pull before you start, push when you stop.** Always get the latest version
   (`git pull`, or "Fetch origin" then "Pull" in GitHub Desktop) before editing.
2. **Markdown merges, Word does not.** Two people can edit the same `.md` file and
   Git will combine their changes. Two people editing the same `.docx` at the same
   time will produce a conflict that Git cannot merge, and one person's work
   will have to be redone by hand. So:
   - Draft and discuss text in `.md` files.
   - Each `.docx` has one owner at a time. Say in the group before you open one.
3. **One topic per commit, with a clear message**, for example
   `Ch1: draft 1.2 Problem Statement` or `Ch1: fix Hager et al. citation`.
4. **Citations.** Only cite a source at the level it was verified (see the
   labels at the top of the evidence report). Unverified figures are not cited.
